# LoG ControlPanel SDK (AutoHotkey v1)

Dieses Repository enthält ein SDK zur Kommunikation mit dem
Life-of-German Control Panel.

## Features

- CP Login / Logout
- CP Requests (GET/POST)
- Skin-System
- Activity-Points
- Premium-Status
- Abwesenheitsmeldung
- Fahrzeugliste + Parkposition
- Teamliste + Rollen
- JSON-Handling
